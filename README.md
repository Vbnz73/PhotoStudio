# PhotoStudio

Программа для подготовки фотографий на документы.

## Возможности

- Выбор форматов фотографий на документы.
- Кадрирование с сохранением пропорций.
- Автоматическое определение лица и глаз.
- Ручная настройка положения кадра.
- Обработка фона и редактирование маски.
- Работа с каталогом фотографий.
- Экспорт зафиксированной композиции в PNG или JPEG.

## Экспорт фотографии

1. Откройте фотографию, выберите формат, настройте рамку в режиме «Разметка»
   и зафиксируйте её кнопкой «Всё, успокойся, лучше уже не сделаешь».
   При необходимости обработайте фон.
2. Выберите **Файл → Экспорт композиции…** или нажмите **Ctrl+Shift+S**.
   Укажите PPI (по умолчанию 300), затем папку, имя и формат PNG/JPEG.
   Если расширение не указано, оно добавляется по выбранному типу; явное
   расширение `.png`, `.jpg` или `.jpeg` определяет формат файла.
3. При первом открытии диалога размер в пикселях рассчитывается по формату
   при 300 PPI, если результат допустим. Изменение только PPI по умолчанию
   сохраняет этот растр (при повторном экспорте той же композиции — размер
   последнего сохранённого растра). Чтобы
   заново рассчитать пиксели по физическому формату, отметьте соответствующий
   пункт в диалоге. Размер в миллиметрах получается из целого растра и PPI
   и может немного отличаться от заданного.

Экспортируется весь холст зафиксированной композиции, включая белые области,
фон, маски и защищённый уголок, без рамки разметки и прочих экранных наложений.
Композиция вписывается по центру без обрезки и растягивания. В PNG сохраняется
внутренняя прозрачность, в JPEG прозрачные области сводятся на белый. Исходную
фотографию перезаписать нельзя; замена другого существующего файла требует
подтверждения. PNG хранит плотность целым числом пикселей на метр, поэтому
прочитанное PPI может незначительно отличаться от заданного.

Если формат в списке изменён после фиксации, экспортируется формат, который
был зафиксирован вместе с композицией. Чтобы применить новый формат, вернитесь
в разметку и зафиксируйте композицию заново; возврат сбрасывает обработку фона.

## Установка

Для указанной в `requirements.txt` версии NumPy нужен Python 3.12 или новее;
остальные зависимости также должны поддерживать выбранную версию Python.
Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Запустить программу:

```powershell
python main.py
```

## Модель распознавания лица

Файл `face_landmarker.task` должен находиться рядом с `main.py`.
